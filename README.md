# Retail-Sales-Dashboard

## 📌 Project Overview
This is an interactive Retail Sales Dashboard built using Microsoft Excel. It helps analyze retail sales performance using KPIs, Pivot Tables, Pivot Charts, and Slicers.

## 📊 Key Performance Indicators (KPIs)
- Total Sales
- Total Transactions
- Total Customers
- Total Quantity Sold
- Average Unit Price

## 📈 Dashboard Features
- Monthly Sales Trend
- Product Category Analysis
- Male vs Female Sales
- Age Category-wise Sales
- Monthly Transactions
- Quantity Sold by Category
- Interactive Slicers (Year, Month, Gender, Product Category)

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
